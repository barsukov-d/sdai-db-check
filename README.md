# Проверка базы данных

Тестовое приложение self-developer-ai: заметки хранятся в базе данных, адрес которой приходит только из переменной `DATABASE_URL`. Нужно, чтобы проверить, что доступ из раздела «Доступы» доходит до запущенного приложения.

## Запуск

```bash
pnpm install
pnpm start        # http://0.0.0.0:3000, порт меняется переменной PORT
pnpm test
```

Внутри приложения работает маленькая база (порт 5544, меняется переменной `EMBEDDED_DB_PORT`, только 127.0.0.1, пароль она не проверяет). Приложение подключается к ней только по адресу из `DATABASE_URL`, например `postgres://app:любой-пароль@127.0.0.1:5544/postgres`. Без `DATABASE_URL` приложение работает, но пишет «Нет базы».

## Адреса

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/` | страница заметок |
| GET | `/health/db` | есть ли база; метка из таблицы `marker` |
| GET, POST | `/api/notes` | список заметок и добавление `{ "text": "…" }` |
| GET | `/api/health` | проверка, что сервер жив |
